# Vehicle-Mass-Estimation-using-ECU-Data
Intelligent OBW kit estimates vehicle mass in real-time using ECU data (Torque, Speed, RPM) via OBD-II and GRU AI model on Raspberry Pi. Sensor-free, AIS-205 compliant with LCD display &amp; SD logging. Validated on Mahindra KUV100 with 0.52% MAPE. Cost-effective solution.
